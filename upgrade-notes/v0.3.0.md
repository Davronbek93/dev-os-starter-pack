# Upgrading to v0.3.0

## The board doc moved to slot 18

`docs/17-Board.md` is now `docs/18-Board.md`, and slot 17 is `docs/17-Model-Tiers.md`.

If you installed the board from an untagged checkout, re-point your own references:

```bash
grep -rln '17-Board' . --exclude-dir=.git | xargs sed -i '' 's/17-Board/18-Board/g'
```

`devos update` moves the kit's own copy; it cannot rewrite links inside files you have
modified — `devos doctor` lists any that broke.

## The board's git policy changed

The history is committed; the queue is not. The board now writes `<dataDir>/.gitignore`
containing `queue.jsonl` the first time it writes anything. If you committed
`queue.jsonl` earlier, `git rm --cached .devos/queue.jsonl`.

## Task files gain a `## Blocker` section

`node board/cli.mjs block <id> "<reason>"` writes it, placing it before `## Notes`.
Tasks written before this parse fine — the section is created on demand.

## Board configuration moved out of the kit

Project settings belong in `<dataDir>/board.config.json`, not in
`board/board.config.json`, so a kit update never clobbers them. The kit file remains as
the default layer; a project file wins over it.

## Recording is mandatory inside a worktree

The board now resolves to the repository's **main** worktree, so all parallel agents
share one board and task state stays out of per-branch diffs. The corollary: an agent
working in a linked worktree must record through `board/cli.mjs`; editing its own copy of
the task file is invisible until that branch merges.
